# Finite AI aircraft fuel

AI aircraft now carry a finite per-generation sortie budget. Bombers start with 36,000 cruise-tick units (20 minutes at fixed30Hz), fighters with21,600 (12minutes). Ordinary flight consumes one unit per tick; absolute bank at least1rad and upward velocity greater than.1m/tick each add one. This is a bounded sortie/load approximation, not a measured engine fuel-flow model. A3,600-unit reserve triggers the existing owned return/holding policy, cancels combat targeting and retains actual ammunition/health.

Empty fuel forces a powerless glide: the existing vertical actuator converges to−.5m/tick, nose pitch and horizontal travel follow the same conserved-speed flight transform, and the normal swept terrain/solid contact creates the eventual real casualty/wreck. Fuel exhaustion does not instantly explode a plane. Engine loops stop for glide mode, while normal impact audio remains. Airspeed remains the existing role speed; this is a controlled constant-speed glide approximation, not an aerodynamic lift/drag/energy/stall solver. Existing steering and bounded bank remain, with powered climb requests overridden.

NASM owns one16-byte private record per physical entity: generation, remaining units, last-consumed tick and birth role+1. No heap allocation or global target lookup. Birth initialises capacity once; repeated calls in the same fixed tick do not burn again. Consumption saturates at zero; in-flight holding, ammunition changes and repeated queries never refill. Reused genuine generations receive a fresh budget. Fuel lifecycle is included in authoritative replay checksums. Queries leave source/private state and XMM values unchanged; invalid own body/role/speed/bank/vertical metadata or corrupt capacity changes no fuel record.

The public entity32/aircraft64 layouts and64-byte aircraft wire records retain their sizes. Public aircraft mode4 now means powerless glide, so protocol41, schema fingerprint and content fingerprint change together. Both peers must be rebuilt; older incompatible peers are rejected during normal version/fingerprint validation. Raw fuel is authority-private, not a pilot HUD or client-local simulation. The real UDP adapter accepts mode4 atomically and rejects higher malformed modes; recorded aircraft-engine selection observes the replicated mode.

Evidence includes56 native lifecycle/invalid/canary/ABI cases, a full21,600-unit exhaustion, wrapping tick stamp, genuine new generations, read-only/hash controls and both-role reserve/empty causal sim_tick comparisons against omitted policy. A separate original8192 authority sends genuine descending glide records through UDP to the actual NASM adapter after one declared initial own-player/plane/fuel staging. HP/generation/ammunition and subsequent clocks/fuel are not renewed. Production PCM routing verifies engine-loop silence for glide while preserving existing moving-loop/voice-priority coverage. Exact frozen suite results and limitations are in status.md/evidence.

Wing mission eligibility now shares the read-only fuel query. Reserve, empty and corrupt matching-generation fuel records cannot accept escort work as either fighter or bomber. Existing commitments stop providing steering and threat priority immediately; the scheduled30-tick review clears a returning fighter or selects a different eligible bomber. The query preserves friendly-record pointers, owner ID, fallback XMM goals and source/private state. Missing fuel records retain the existing pre-birth query semantics; queries do not initialise or refill them. This corrects planner integration of the existing finite-fuel policy, with no record, protocol or fingerprint change. Both-side native assignments and actual reserve-crossing flights are compared with an omitted-wing-fuel-guard control.

Remaining: landing, finite depot fuel/repair/rearm and transport/airbase logistics; real energy/stalls/lift/drag, throttle/Doppler and physical-device audio craft; wing coordination/air traffic and full operation/art/Windows/performance acceptance. Aircraft that have returned still hold and eventually exhaust fuel; no landing or hidden refill is claimed.
