# Recovery runway admission

A recovering aircraft now needs an exclusive lease before entering or continuing final approach. Each of the six runways owns a16-byte record: physical ownerID+1, owner generation, last successful guidance tick and side. Six records total96 bytes. Zero means no owner; a malformed empty record fails closed. Admission validates genuine owned recovery eligibility, nonempty valid fuel and the current selected usable facility. First eligible request in deterministic authoritative actor order wins. Other arrivals remain in their powered circuit; their real finite fuel continues to burn.

A continuing owner renews its lease on every guidance query. Sixty ticks without guidance expire the claim. Natural uint32 tick wrap works; ambiguous future timestamps fail closed. Death, kind/generation changes, inactive aircraft and capture invalidate the previous claim. Ownership is checked before reading an occupant's condition/private aircraft; stale opposite-side claims are discarded without inspecting enemy aircraft. Go-around, loss of recovery eligibility, base changes and new generation release the requesting physical ID's own claims, including stale generations. No other ID's lease is released. Boundary/world/threat/separation priority remains in existing flight code; interrupted guidance can therefore leave a short lease until expiry.

`air_traffic_request(EDI own ID, ESI selected base)` returns1 grant/renew,0busy or−1invalid. It preserves all SysV nonvolatile GPRs and XMM0..7, aligns nested calls and changes only the selected lease. All public bodies/facilities/fuel remain read-only. `air_traffic_release(EDI own ID)` scans only six entries, returns released count0..6 or−1invalid bounds, and changes only matching owner records. Init clears96 bytes; hash appends every lease byte to same-build replay. No heap, unbounded scan, queue or quadratic all-actor search. The implementation assumes the existing single authoritative update thread; future parallel pilot jobs must serialize admission or add atomic transactions.

Approach policy2 and traffic policy1 are included in the compatibility fingerprint. Public/wire record sizes andAIR_RETURN mode remain unchanged. UDP44/schema0x0bf88488/content0x0238d9f7 require rebuilt peers. Leases are server-private scheduling state, not a new replicated user interface.
