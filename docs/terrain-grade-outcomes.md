# Raised terrain gameplay outcomes

The independent `tests/test_terrain_grade_outcomes.py LIBRARY --report REPORT` observer drives the actual authoritative game using `sim_init`, orders, waypoints, `player_input`, boarding, exit, and `sim_tick`. It does not call grade or motion actuators, write motion sidecars, renew health, disable hazards, or substitute a flattened terrain profile. Sparse initial births are development fixtures, not army-scale acceptance.

Canonical relief geometry is read independently from `content/terrain/relief.json`. The observer computes the full hill plus the original bowl/ridge height and combined analytic gradients. For each accepted movement it samples the actual swept vehicle circle, endpoints, intermediate body positions, relevant canonical break intersections, and one-sided cusp gradients. Samples are independent evidence of actual behavior, not a proof of continuous clearance everywhere. The separate assembly grade kernel must prove its conservative bound.

The central western ramp must reject direct tank driving before the whole hull enters the steep face. AI tanks and artillery must reach the plateau using useful safe routes. Their finite route deadlines derive from the explicit outer bypass corners and gentle east entrance, the physical off-road cap, and a bounded turning/arrival allowance. Existing scale, health and navigation acceptance deadlines are unchanged. Additional cases cover a combined-gradient corner stop, useful parallel motion with the whole body clear of the steep face, gentle ascent/descent, an actual moderate fringe reachable by tanks and rejected by artillery, uphill/downhill driver speed and raised eye position, camera independence, bounded reversal, physical driver-to-AI handoff, malformed public input preservation and exact same-build world replay.

The immutable prior accepted library serves as a causal negative for missing raised height and missing slope rejection. Candidate outcomes are accepted only after running against an actual frozen integrated root library. This observer does not establish shortest routes, per-role navigation caches, suspension, wheeled behavior, oriented collision bodies, rendered quality, target GPU performance, or dense scale acceptance.
