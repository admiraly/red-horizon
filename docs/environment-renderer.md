# Terrain textures and cosmetic weather

The Linux client uploads the four real photographed CC0 terrain materials from `content/textures/terrain.rhtx` to one OpenGL RGBA8 2D array, with repeat addressing and generated mipmaps. Layers are Leafy Grass, Brown Mud, Gravel Ground 01 and Rocky Terrain. Source attribution, original files and offline conversion belong to the content manifest and texture bake report. The authored runtime loader, controls and transition state are NASM; Python tests and image conversion are development tools only.

RHTX v1 has eight little-endian u32 fields: literal `RHTX`, version 1, total size 4194336, width 512, height 512, layers 4, payload offset 32, format 1 (RGBA8). Exactly 4194304 payload bytes follow, each layer bottom-up. Missing files, extra or truncated bytes, and any inconsistent header field fail startup with a useful texture-pack error. The fixed arena reads at most the expected size plus one byte; no runtime image decoder or per-frame asset allocation is used.

The terrain fragment shader tiles source images at approximately 2.5–5 metres, blends grass/mud patches, gravel across the three strategic corridors and objective areas, and rock on slopes. Shared ground and source-mesh lighting shifts from directional clear light to softer overcast light. Rain darkens ground and adds a restrained rough specular lobe. The micro variation derives from albedo derivatives, not an authored normal texture or a complete physically based material system. Terrain height, collision, lines of sight, AI and networking remain authoritative and unchanged.

`--weather clear|overcast|rain|fog` selects the initial preset; clear is the default. F4 cycles through the four presets and the title names the selected target. Cloud, precipitation and fog values approach that target smoothly instead of jumping. All clients may choose their own cosmetic preset. The shared `weather` vec4 is render time, cloud coverage, rain amount and additional exponential fog density. The sky uses a gradient and three bounded procedural cloud octaves drifting with cosmetic wind. Rain draws 512 world-space falling/wind-driven streaks in a bounded region around the camera and hides below terrain. The rain pool does not create damage, concealment, puddle collision or gameplay events. Clouds and precipitation do not constitute an authoritative environmental simulation.

HUD, tactical glyphs, projectile/tracer/impact colours and the first-person rifle remain readable without weather fog. Source models retain their team distinction and source animation. Tactical mode keeps its live terrain map and hides sky/rain. There are no changes to global framebuffer sRGB handling or recorded audio routing.

Verification uses the actual texture pack and assembled executable. `tests/test_texture_assets.py LIBRARY PACK` verifies valid loading, thirteen malformed/missing rejections, recovery, named presets and bounded smooth state transitions. A test library can be linked from the real environment object with `cc -shared -Wl,-Bsymbolic -o build/libenvironment.so build/src_render_environment.asm.o -lGL`.

`tests/test_client_environment.py CLIENT` starts a private Xvfb with software OpenGL, renders all four real presets, checks source ground detail and changed sky/ground pixels, and sends actual F4 input through XTest. It confirms unchanged player position, health, ammunition, shots and generation through the weather cycle. Current focused evidence: clear ground mean RGB about 128/114/89 versus rain 74/67/53; source ground red-channel range 115–141. Preset screenshots are written to `/tmp/rh-weather-{clear,overcast,rain,fog}.ppm`. These are software rendering and input checks, not reference GPU performance or production atmospheric quality claims.

The precipitation regression freezes only its own private child simulation/animation clocks and compares actual dry/wet GL pixels at two controlled cosmetic phases. Forward view produced 500/488 rain pixels with 968 moved pixels; the 90-degree view produced 449/701 with 1150 moved pixels. The width follows camera right while centres still fall and drift in world coordinates. No authoritative tick advances in these development fixtures. Off-corridor ground images at world x2000/z2200 are written to `/tmp/rh-weather-off-corridor-grass.ppm` and `/tmp/rh-weather-off-corridor-rain.ppm`. Fixture pose/time writes are explicit test setup, distinct from the unmodified-player F4 check.

Existing actual first-person/tactical graphics, controls and authoritative player gameplay tests passed on the textured clear-default build; the final rain-width change is additionally verified by the focused precipitation regression. The integrator runs the complete frozen verification across simulation, source meshes, effects and transport.
