# Bounded combat cosmetics

The first cosmetic slice reads all four authoritative player records. Every third new rifle shot can emit one thin world-space tracer. A64record/32byte fixed pool rotates on saturation; render-time lifetimes are independent of simulation ticks. Generation changes baseline counters, repeated snapshots/render frames emit nothing, and skipped snapshot intervals collapse to one current cosmetic tracer rather than replay old fire. Authority records remain untouched. The tracer represents a cosmetic100m aim direction, not an exact hit point or ballistic trajectory. No impact location is invented from a hit counter.

`python3 tests/test_client_effects.py CLIENT` drives actual held fire on private Xvfb, reads only counters and cosmetic pool state, captures actual pixels, verifies one tracer for three shots, absence of duplicate emission on later frames, and expiry. The driver temporarily pauses only its owned client while recording the screenshot. Software OpenGL rendering validates the path, not target GPU budgets or human visual quality. Screenshot `/tmp/red-horizon-tracer.ppm` is a development artifact. The final committed test result is recorded at integration.
